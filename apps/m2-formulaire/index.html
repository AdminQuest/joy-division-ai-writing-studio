Formulaire M2

Saisie locale pour preparer les commandes et JSON des flux M2.

Mode d'emploi

Le formulaire prepare. La CLI diagnostique. L'humain valide.

Workflow : Formulaire -> Commande ou JSON -> CLI M2 -> Diagnostic -> Resume PR -> Validation humaine.

Usages

  • PERSON : preparer une personne candidate.
  • ORG : preparer une organisation candidate.
  • PLACE : preparer un lieu candidat.
  • IMAGE : preparer une image ou seance iconographique candidate.
  • SOURCE LONGUE : diagnostiquer une source candidate.
  • BATCH : preparer une campagne d'objets.

Limites

Le formulaire ne cree pas de personne, organisation, lieu, image canonique, source canonique, atome, citation, relation, modification de registre ou PR GitHub.

Apres copie

  1. Executer la commande depuis la racine du depot.
  2. Lire le diagnostic et le resume exports/generated/pr_summary_*.md.
  3. Traiter les reserves puis soumettre a revue humaine.
