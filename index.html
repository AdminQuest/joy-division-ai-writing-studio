Mode d’emploi minimal

Le portail est le point d’entrée unique du dépôt. Il donne accès au RAG Studio, aux ateliers de rédaction et aux ateliers de validation documentaire. Ces espaces restent séparés afin de distinguer clairement trois opérations : retrouver les sources, rédiger le livre, contrôler les références.

1. Reconstruire les exports

Depuis la racine du dépôt, lancer :

python tools/build_registers.py

Cette commande doit être exécutée avant toute session de travail, puis relancée après toute modification d’une fiche source, d’un document maître, du registre des références, du fichier des citations vérifiées ou du tableau de cohérence thématique.

2. Lancer le serveur local

Depuis la racine du dépôt, lancer :

python tools/rag_server.py

Le terminal doit rester ouvert pendant toute la session. S’il est fermé, le serveur s’arrête.

3. Ordre de travail recommandé

  1. Reconstruire les exports avec build_registers.py.
  2. Lancer le serveur avec rag_server.py.
  3. Interroger les sources dans le RAG Studio.
  4. Rédiger dans l’atelier de rédaction à partir des sources retrouvées.
  5. Contrôler le texte dans l’atelier de validation : sources, citations, doublons, périmètre du chapitre.

4. Règle de contrôle

Aucun passage n’est stabilisé tant que la source n’est pas identifiable, que les citations verbatim ne sont pas vérifiées, que le chapitre d’accueil n’est pas confirmé et que le tableau de cohérence thématique n’exclut pas un doublon.
