RAG Studio

  • recherche texte simple ;

  • résultats sourcés par fichiers et identifiants.

Mode d’emploi minimal

Avant d’utiliser le RAG Studio, générer les exports depuis la racine du repo :

python tools/build_registers.py

Puis lancer le serveur local :

python tools/rag_server.py

Le portail reste le point d’entrée unique. Les ateliers demeurent séparés pour éviter de mélanger rédaction, retrieval et validation documentaire.
