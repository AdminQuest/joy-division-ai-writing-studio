# Routage historiographique automatique des prompts

Le repo introduit désormais une couche de pilotage automatique des prompts.

Objectif :

adapter automatiquement les instructions IA selon :

- les risques historiographiques ;
- les couches narratives ;
- les mythes ;
- les densités théoriques ;
- les motifs dominants ;
- les niveaux de preuve.

---

# 1. Principe général

Un prompt n’est plus neutre.

Il doit être ajusté dynamiquement selon le contexte documentaire.

Exemple :

un chapitre fortement théorique nécessitera :

- réduction des références Fisher ;
- retour au terrain ;
- augmentation des faits matériels ;
- limitation des extrapolations.

---

# 2. Routage par risque historiographique

## Si risque de téléologie élevé

Injecter automatiquement :

```text
Éviter toute impression d’inévitabilité historique.
Rappeler les contingences, hésitations et bifurcations.
```

---

## Si risque de mythologisation élevé

Injecter :

```text
Distinguer explicitement faits établis, mémoire subjective et reconstruction postérieure.
```

---

## Si risque de psychologisation

Injecter :

```text
Ne pas réduire l’œuvre à une lecture psychologique univoque.
Préserver la dimension collective et matérielle.
```

---

# 3. Routage par couche narrative

## Historique

Favoriser :

- précision ;
- chronologie ;
- sources ;
- matérialité.

---

## Théorique

Limiter :

- accumulation conceptuelle ;
- paraphrase philosophique ;
- surplomb analytique.

---

## Sensible

Favoriser :

- texture ;
- spatialité ;
- ambiance ;
- matérialité sonore.

---

# 4. Routage par motifs

## Spectralité

Limiter :

- excès métaphoriques ;
- généralisation hantologique.

---

## Ruine industrielle

Limiter :

- romantisation du déclin ;
- esthétisation des friches.

---

# 5. Routage par densité théorique

Si accumulation :

```text
Fisher
Derrida
Bauman
théorie critique
```

alors injecter :

```text
Revenir aux pratiques musicales, aux lieux, aux instruments, aux corps et aux situations concrètes.
```

---

# 6. Objectif stratégique

Le système doit progressivement devenir capable de :

- corriger les dérives du manuscrit ;
- équilibrer automatiquement les chapitres ;
- adapter les prompts selon le contexte ;
- maintenir une cohérence historiographique globale.
