# S41 — Peter Hook — Registre normalisé des citations exactes

## Fonction du fichier

Ce fichier rassemble les citations exactes courtes issues de Peter Hook, *Unknown Pleasures: Inside Joy Division*.

Il distingue :
- la citation originale ;
- la traduction littérale ;
- la traduction éditoriale ;
- l’enjeu de traduction ;
- le statut de vérification ;
- les risques d’usage.

Règle d’usage :
- conserver l’anglais comme texte source maître ;
- ne jamais remplacer l’original par une traduction ;
- utiliser la traduction française comme outil rédactionnel ;
- vérifier toute citation avant intégration dans le manuscrit ;
- privilégier les citations courtes ;
- préférer la paraphrase analytique lorsque la formulation originale n’a pas de valeur stylistique propre.

## Règles de traduction et d’intégration

1. La citation originale anglaise reste le texte maître.
2. La traduction littérale sert au contrôle du sens.
3. La traduction éditoriale sert à l’écriture française du livre.
4. Les passages à enjeu idiomatique doivent être signalés explicitement.
5. Toute citation intégrée dans le manuscrit doit conserver son identifiant `S41-QXXX` jusqu’à la dernière relecture.
6. Les citations sensibles — maladie, suicide, conflits internes — doivent être utilisées avec sobriété et sans dramatisation.
7. Les formules humoristiques de Hook doivent être identifiées comme telles : elles ne constituent pas toujours des descriptions historiographiques neutres.
