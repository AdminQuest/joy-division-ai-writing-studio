# S45 — Deborah Curtis — Atomisation 02

## Segment traité

- Source : Deborah Curtis, *Touching from a Distance: Ian Curtis and Joy Division*, Faber & Faber, 1995.
- Segment : chapitres centraux autour de Factory, *Unknown Pleasures*, grossesse, épilepsie, montée du succès et désorganisation domestique.
- Pages PDF atomisées : 77 à 145 environ.
- Continuité : cette fiche poursuit la numérotation atomique après `atomisation_01_enfance_mariage_warsaw.md`, à partir de S45-016.

## Fonction du segment

Ce segment est crucial parce qu’il documente la collision progressive entre :
- la montée de Joy Division ;
- l’installation de l’épilepsie ;
- la grossesse de Deborah ;
- la vie domestique ;
- la professionnalisation du groupe.

Le livre cesse ici d’être seulement biographique. Il devient le récit d’un déséquilibre structurel : le groupe absorbe progressivement Ian Curtis pendant que le foyer se désorganise.
