## Fonction documentaire

Cette source constitue un cadre critique majeur pour situer Joy Division dans le post-punk britannique : dépassement de punk, culture DIY, labels indépendants, Manchester, Factory Records, Peter Saville, J. G. Ballard, Martin Hannett, basse mélodique, espace sonore, esthétique industrielle, réception critique et passage ultérieur vers la new pop.

## Règle d’usage

S72 est une source critique de synthèse. Elle est précieuse pour formuler des cadres d’interprétation, mais ne doit pas remplacer les sources primaires pour les faits biographiques précis, les dates de sessions, les contrats ou les témoignages directs.
