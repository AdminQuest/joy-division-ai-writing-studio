## Règle d’usage

S71 est utile comme source secondaire de synthèse et comme passerelle entre Joy Division et New Order. Le livre est riche en citations d’acteurs de Factory, mais ces citations doivent être distinguées du commentaire de Claude Flowers.

Les sections New Order postérieures à *Technique* et la discographie finale n’ont pas encore fait l’objet d’une atomisation fine. Cette première passe couvre les nœuds utiles pour le projet Joy Division et les continuités les plus importantes vers New Order.
