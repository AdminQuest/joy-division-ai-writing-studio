## Fonction documentaire

Cette source est réservée à l'ouvrage de Chris Ott consacré à *Unknown Pleasures* dans la collection 33 1/3.

Elle doit être utilisée pour les axes suivants :

- lecture critique de *Unknown Pleasures* ;
- production et fabrication sonore de l’album ;
- rôle de Martin Hannett ;
- tensions entre témoignage, analyse critique et reconstruction ;
- mythologies de studio ;
- réception critique de l’album ;
- distinction entre récit esthétique et fait établi.

## Risques de confusion

Ne pas confondre cette source avec :

- S41 — Hook, *Unknown Pleasures*, 2012 : mémoire interne de Peter Hook ;
- S45 — Curtis, *Touching from a Distance*, 1995 : mémoire intime de Deborah Curtis ;
- S72 — Reynolds, *Rip It Up and Start Again*, 2005/2006 : contextualisation post-punk ;
- S74 — Middles, *From Joy Division to New Order*, 1996 : récit Factory / Manchester / New Order.

Le titre *Unknown Pleasures* désigne ici le livre de Chris Ott, non l’album seul, ni le mémoire de Peter Hook.
