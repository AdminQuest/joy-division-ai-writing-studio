# S47 — *Joy Division* — Mike West — atomisation 01

Source : Mike WEST, *Joy Division*, Babylon Books, 1983.

Nature : source secondaire de synthèse, fortement marquée par la réception critique britannique 1979-1982.

Périmètre de cette première atomisation :
- origines de Warsaw ;
- transformation esthétique 1977-1978 ;
- Factory ;
- John Peel sessions ;
- économie Factory ;
- live ;
- mythologie critique ;
- transition vers New Order.
