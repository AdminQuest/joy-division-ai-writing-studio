# S47 — *Joy Division* — Mike West — atomisation 03

Suite de l’atomisation du livre de Mike West, *Joy Division*, Babylon Books, 1983.

Périmètre :
- discographie détaillée ;
- collectors checklist ;
- films et vidéos ;
- index des chansons ;
- statistiques ;
- objets discographiques rares ;
- corrections de méthode pour exploitation du livre.
