## S60 — Pulsar, t-shirt et mémoire sociale mobile

S60 est central pour le chapitre 14. Federici permet de traiter le motif pulsar d’*Unknown Pleasures* comme icône visuelle devenue vêtement, marchandise, signe d’identité, surface de distinction et mémoire sociale mobile. Le chapitre permet de dépasser l’alternative pauvre entre pure trahison commerciale et pure fidélité subculturelle.

Atomes prioritaires : S60-A001 ; S60-A002 ; S60-A003 ; S60-A004 ; S60-A005 ; S60-A007 ; S60-A008 ; S60-A009 ; S60-A011 ; S60-A014 ; S60-A015.

Apport au chapitre : écrire le devenir contemporain de Joy Division par la circulation matérielle d’un signe. Le pulsar n’est plus seulement une pochette ; il circule sur des corps, dans la mode, les rues, les magasins, les réemplois graphiques et les marchés.

Règle d’usage : rester analytique, non moraliste. Distinguer marchandisation, appropriation, distinction, mémoire, usage réel et décontextualisation. Croiser avec S48 pour la genèse graphique et avec S61 si le traitement juridique des marques est ouvert ultérieurement.
