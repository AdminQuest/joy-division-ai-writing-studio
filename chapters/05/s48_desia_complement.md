## Usage pour le chapitre 5

S48 est directement utile pour traiter le premier régime visuel de Joy Division : *An Ideal for Living*, le tambour hitlérien, le nom Joy Division, les caractères gothisants et la polémique initiale sur d’éventuelles sympathies néonazies.

La source permet d’écrire la force connotative du signe, mais elle ne suffit pas pour conclure sur l’intention politique. Elle doit être croisée avec les sources discographiques, les témoignages du groupe et les sources Factory.
