# Single Source of Truth

## Objet

Le repo adopte désormais une doctrine stricte de :

```text
Single Source of Truth
```

Objectif :

éviter les duplications documentaires et les divergences silencieuses.

---

# 1. Principe fondamental

Toute information structurante doit posséder :

- un emplacement maître ;
- une version de référence ;
- une responsabilité documentaire claire.

---

# 2. Sources

Les sources primaires restent l’unique référence documentaire.

Les synthèses ne doivent jamais remplacer les sources.

---

# 3. Atomes

Les atomes deviennent l’unique unité documentaire réutilisable.

Le manuscrit ne doit pas contenir d’informations critiques absentes des atomes.

---

# 4. Registres

Les registres doivent consolider.

Ils ne doivent pas devenir des espaces parallèles d’analyse libre.

---

# 5. Documents maîtres

Les documents maîtres deviennent :

- couches rédactionnelles ;
- synthèses ;
- états narratifs.

Ils ne constituent plus la vérité documentaire du projet.

---

# 6. Risques principaux

Le repo doit éviter :

- doublons ;
- variantes concurrentes ;
- reformulations divergentes ;
- citations contradictoires ;
- concepts instables.

---

# 7. Doctrine critique

Toute nouvelle information doit répondre à la question :

```text
Quel est son emplacement maître ?
```

Si la réponse est floue,
la structure documentaire n’est pas suffisamment stabilisée.
