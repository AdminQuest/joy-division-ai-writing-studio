# Politique anti-redondance

## Objet

Le repo doit désormais limiter activement les redondances documentaires.

Le principal risque du projet n’est plus le manque d’informations.

Le principal risque devient :

```text
la duplication silencieuse
```

---

# 1. Types de redondances à éviter

## Redondance documentaire

Même information présente dans plusieurs fichiers concurrents.

---

## Redondance citationnelle

Même citation utilisée sans contrôle de version.

---

## Redondance conceptuelle

Même concept reformulé sous plusieurs noms.

---

## Redondance narrative

Même démonstration répétée dans plusieurs chapitres.

---

# 2. Doctrine de réduction

Toute information critique doit avoir :

- un emplacement maître ;
- une version canonique ;
- des renvois plutôt que des duplications.

---

# 3. Signaux d’alerte

Les symptômes suivants indiquent une dérive documentaire :

- plusieurs définitions concurrentes ;
- citations divergentes ;
- concepts proches non stabilisés ;
- répétitions fréquentes ;
- reformulations non contrôlées.

---

# 4. Principe important

Le repo doit privilégier :

```text
liaisons
renvois
graphes
relations
```

plutôt que :

```text
duplication
copie
réécriture multiple
```

---

# 5. Objectif final

Le système doit progressivement devenir :

- compact ;
- cohérent ;
- relationnel ;
- historiographiquement gouvernable.
