# Guide d’homogénéisation

## Objet

Ce document fixe les règles d’homogénéisation progressive du repo.

Le système doit progressivement réduire :

- les écarts de structure ;
- les variantes documentaires ;
- les différences de format ;
- les ambiguïtés de schéma.

---

# 1. Principe général

Tout nouveau contenu doit désormais :

- respecter les schémas stabilisés ;
- utiliser les conventions officielles ;
- éviter les champs improvisés ;
- éviter les structures parallèles.

---

# 2. Atomes

Les atomes doivent progressivement converger vers :

- les mêmes champs ;
- les mêmes conventions ;
- les mêmes niveaux de preuve ;
- les mêmes structures relationnelles.

---

# 3. Concepts

Les concepts doivent utiliser :

- une définition canonique ;
- un identifiant stable ;
- des relations explicites ;
- une stabilité terminologique.

---

# 4. Registres

Les registres doivent rester :

- consolidés ;
- homogènes ;
- non redondants ;
- compatibles avec les exports.

---

# 5. Doctrine importante

L’homogénéité documentaire devient désormais plus importante que l’enrichissement rapide.
