# Chaînes argumentatives

Le repo distingue désormais :

- les atomes ;
- les concepts ;
- les relations ;
- les chaînes argumentatives.

Les chaînes argumentatives représentent les raisonnements structurants du livre.

---

# 1. Définition

Une chaîne argumentative relie plusieurs unités documentaires pour produire une démonstration.

Exemple :

```text
industrialisation
→ désindustrialisation
→ fragmentation urbaine
→ désaffiliation sociale
→ intériorisation affective
→ spatialisation sonore
→ esthétique Joy Division
```

Cette structure dépasse le simple stockage documentaire.

Elle modélise la logique du livre.

---

# 2. Fonction

Les chaînes argumentatives servent à :

- stabiliser les démonstrations ;
- éviter les contradictions interchapitres ;
- limiter les répétitions ;
- détecter les raccourcis interprétatifs ;
- mesurer les dépendances théoriques.

---

# 3. Types de chaînes

## Chaîne historique

Exemple :

```text
crise industrielle
→ chômage
→ fragmentation urbaine
→ mutation culturelle
```

---

## Chaîne esthétique

Exemple :

```text
production Hannett
→ spatialisation sonore
→ sensation spectrale
→ réception critique
```

---

## Chaîne mémorielle

Exemple :

```text
mort de Ian Curtis
→ reconstruction médiatique
→ patrimonialisation
→ mythe culturel
```

---

## Chaîne théorique

Exemple :

```text
Derrida
→ Fisher
→ hauntologie
→ Joy Division
```

---

# 4. Risques

Les chaînes argumentatives peuvent dériver.

Risques principaux :

- téléologie ;
- déterminisme ;
- sursymbolisation ;
- causalité simplifiée.

Toute chaîne doit donc rester :

- historiquement prudente ;
- documentée ;
- réversible ;
- nuançable.

---

# 5. Objectif long terme

Les chaînes argumentatives préparent :

- une supervision éditoriale automatisée ;
- des diagnostics de cohérence ;
- des graphes dynamiques ;
- des analyses de dépendance théorique.
