# Moteur de cohérence narrative

Le repo entre désormais dans une phase de supervision globale du manuscrit.

Objectif :

- surveiller la cohérence interchapitres ;
- limiter les redondances ;
- détecter les dérives théoriques ;
- équilibrer les couches narratives ;
- contrôler les mythologisations.

---

# 1. Principe

Le manuscrit n’est plus traité comme une suite de chapitres indépendants.

Le système doit désormais surveiller :

- les circulations de concepts ;
- les répétitions ;
- les contradictions ;
- les dépendances théoriques ;
- les densités émotionnelles.

---

# 2. Contrôles prioritaires

## Redondances

Détecter :

- répétitions argumentatives ;
- répétitions de citations ;
- répétitions conceptuelles.

---

## Densité théorique

Détecter :

- accumulation Fisher ;
- accumulation Derrida ;
- accumulation théorie critique.

Objectif :

préserver la matérialité du groupe.

---

## Mythologisation

Détecter :

- prophétisation rétrospective ;
- téléologie ;
- dramatisation excessive ;
- réduction de Joy Division au suicide.

---

## Déséquilibres narratifs

Détecter :

- tunnels analytiques ;
- tunnels mémoriels ;
- saturation mélancolique ;
- sous-documentation factuelle.

---

# 3. Objectif long terme

Le moteur de cohérence prépare :

- supervision éditoriale automatisée ;
- cartographie dynamique du livre ;
- heatmaps émotionnelles ;
- diagnostics de densité ;
- contrôle historiographique assisté par IA.
