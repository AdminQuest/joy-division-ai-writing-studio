# Stratification narrative

Le manuscrit Joy Division comporte plusieurs couches narratives simultanées.

Ces couches doivent désormais être explicitement surveillées.

Objectif :

- éviter les déséquilibres ;
- contrôler la densité théorique ;
- préserver les respirations ;
- éviter la saturation mélancolique ;
- maintenir la lisibilité historiographique.

---

# 1. Couches narratives identifiées

## Historique

Fonction :

- faits ;
- chronologie ;
- contexte ;
- événements.

---

## Analytique

Fonction :

- interprétation ;
- mise en relation ;
- articulation documentaire.

---

## Théorique

Fonction :

- mobilisation conceptuelle ;
- philosophie ;
- cultural studies ;
- sociologie.

Risque :

- tunnels théoriques ;
- surplomb analytique.

---

## Mémorielle

Fonction :

- témoignages ;
- souvenirs ;
- reconstructions.

Risque :

- mythologisation ;
- reconstruction rétrospective.

---

## Sensible

Fonction :

- texture ;
- ambiance ;
- affects ;
- spatialité.

Risque :

- lyrisation excessive ;
- abstraction affective.

---

## Quasi-littéraire

Fonction :

- intensification narrative ;
- ouverture de chapitre ;
- scènes.

Risque :

- dramatisation ;
- esthétique du destin.

---

# 2. Doctrine d’équilibre

Le livre doit alterner :

- faits ;
- analyses ;
- affects ;
- respiration documentaire.

Aucune couche ne doit absorber les autres.

---

# 3. Surveillance particulière

Le projet Joy Division présente trois risques structurels majeurs :

- téléologie ;
- mélancolisation générale ;
- prophétisation rétrospective.

La stratification narrative sert à limiter ces dérives.
