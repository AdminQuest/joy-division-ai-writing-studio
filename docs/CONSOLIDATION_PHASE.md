# Phase de consolidation

Le repo entre officiellement dans une phase de consolidation documentaire.

Objectifs prioritaires :

- homogénéiser les structures ;
- réduire les écarts de format ;
- limiter les redondances ;
- stabiliser les schémas ;
- améliorer la maintenabilité.

---

# 1. Migration progressive des anciens contenus

Les anciens contenus doivent désormais être migrés progressivement vers :

- les schémas v2 ;
- les relations ;
- les niveaux de preuve ;
- les couches narratives.

La migration doit rester :

- incrémentale ;
- non destructive ;
- traçable.

---

# 2. Homogénéisation documentaire

Le repo doit tendre vers :

- une structure atomique homogène ;
- des conventions stabilisées ;
- des registres cohérents ;
- des diagnostics reproductibles.

---

# 3. Réduction des écarts structurels

Les différences suivantes doivent progressivement disparaître :

- variantes de champs ;
- formats concurrents ;
- nomenclatures divergentes ;
- doublons conceptuels.

---

# 4. Priorité méthodologique

La priorité du projet devient désormais :

solidité documentaire

avant :

expansion fonctionnelle

---

# 5. Critère de maturité

Le repo devient mature lorsque :

- les nouveaux contenus s’intègrent naturellement ;
- les schémas cessent d’évoluer ;
- les registres restent cohérents ;
- les diagnostics restent stables ;
- les automatisations deviennent prévisibles.
